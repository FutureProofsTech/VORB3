## 3. Phase 2 field/CT foundation (checkpoint)

Implemented:

- `vorb3/src/ct.rs` — `CtChoice` masks, constant-time equality/zero tests,
  masked selection, black-box barriers.
- `vorb3/src/field.rs` — GF(2^288) polynomial arithmetic modulo
  `x^288 + x^11 + x^10 + x + 1`:
  - 36-byte little-endian canonical encoding
  - fixed-iteration carry-less multiplication
  - masked bitwise reduction
  - addition/subtraction (XOR), multiplication, squaring
  - fixed square-and-multiply inversion with `0^-1 = 0`
  - constant-time zero/equality internals; public `PartialEq` declassifies
- `vorb3/tests/field.rs` — independent KAT vectors generated by the Python
  model:
  - multiplication
  - addition
  - squaring
  - inversion
  - encoding round-trip
  - field laws
- `kat/field_sp288_diff.bin` — 512 independent Python-model records
  (`a`, `b`, `a*b`, `a^-1`), checked by `vorb3/tests/field_diff.rs`.
- Itoh–Tsujii inversion: 16 chain multiplications plus fixed squarings.
- `vorb3/src/zeroize.rs` — safe `fill(0)` + `black_box` wipes; `F288::wipe`.
